# Brand Guide

## Name

**MediaForge** (working and current project name). See [BRANDING_REPORT.md](BRANDING_REPORT.md) for conflict notes.

## Tagline

*Multimedia engineering on the FFmpeg foundation.*

## Tone

Precise, technical, honest about limits. No hype, no “we invented codecs.”

## Colors (suggested)

| Role | Light | Dark |
|------|-------|------|
| Primary | `#1a5f7a` | `#5eb1d4` |
| Accent | `#c45c26` | `#e89a6a` |
| Neutral text | `#1b1b1b` | `#e8e8e8` |
| Background | `#ffffff` | `#121212` |

## Typography

- UI/docs: system sans (Inter, Helvetica, Segoe UI)
- Code: monospace (JetBrains Mono, Consolas, ui-monospace)

## Logo

SVG mark in `assets/branding/` — geometric “M” + frame motif; **not** derived from the FFmpeg logo.

## Do / Don’t

| Do | Don’t |
|----|-------|
| Credit FFmpeg clearly | Copy FFmpeg logos or imply endorsement |
| State pre-release honestly | Claim unmeasured “100% tested” |
| Use MediaForge for project-owned work | Attribute upstream codecs as MediaForge inventions |
