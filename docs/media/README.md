# Media Processing (MediaForge)

MediaForge builds on **upstream FFmpeg** capabilities. This directory documents inventory, prioritization, designs, and MediaForge-specific helpers—not a second codec stack.

| Document | Purpose |
|----------|---------|
| [FEATURE_INVENTORY.md](FEATURE_INVENTORY.md) | What already exists upstream |
| [ROADMAP.md](ROADMAP.md) | Prioritized improvements |
| [FEATURE_DESIGN.md](FEATURE_DESIGN.md) | Designs for Phase 6 selections |
| [MEDIA_PROCESSING_REPORT.md](MEDIA_PROCESSING_REPORT.md) | Phase 6 report |
| [../UPSTREAM_STRATEGY.md](../UPSTREAM_STRATEGY.md) | How we track upstream |

**Tools**: `ffmpeg`, `ffprobe`, optional `scripts/mediaforge` (inspect / thumbnail / extract-audio / passthrough).
